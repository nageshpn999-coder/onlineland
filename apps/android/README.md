# apps/android — OnlineLand Android app

Flutter + Dart app for Google Play, using the same Firebase project as the website.

**Status:** folder reserved in Phase 2. Created in **Phase 6** with `flutter create`.

Planned: Riverpod (state), go_router (navigation), Firebase Auth (phone OTP + Google), Firestore, Storage, Cloud Messaging, App Check (Play Integrity), Telugu + English via ARB files.

Never commit `google-services.json`, `key.properties` or keystores — they are git-ignored.
