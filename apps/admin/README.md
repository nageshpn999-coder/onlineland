# apps/admin — OnlineLand admin dashboard

Private dashboard at **admin.onlineland.in** (Next.js + TypeScript, separate Vercel project).

**Status:** folder reserved in Phase 2. Built in **Phase 7**: listing approvals, owners/dealers, customers, CRM and lead assignment, site visits, featured listings and subscriptions (manual UPI confirmation), reports.

Every page and server action requires the `admin` custom claim (agents get a limited view of their own leads).
